# Тесты проекта

Автоматические тесты: `../backend/src/test/`, `../frontend/src/**/*.test.js`, `../ml/tests/`. Команды приведены в README и паспорте. Общая E2E-проверка — `../scripts/smoke.ps1`.

`fixtures/lecture.png` создана программно для ЛР № 1 из собственного текста `lecture.txt`, без сторонних фотографий. Проверяется ключевое слово transaction, непустые OCR и краткое содержание, а также отсутствие сообщения о сбое суммаризации. Полный ответ модели побуквенно не сравнивается.

Smoke создаёт два уникальных технических аккаунта и один конспект; удаляет только созданный им конспект. Учётные записи остаются в тестовой базе. При ошибке конспект сохраняется для диагностики; токены и пароли в JSON-отчёт не записываются. Для чистых прогонов использовать отдельный Compose project и новые volumes.
