# Исходный код

Проект состоит из самостоятельных компонентов. Исходники находятся в `../backend/src/main/`, `../frontend/src/` и `../ml/`. Этот каталог — навигационный указатель для структуры курса; код не копируется и не переносится. Такое соответствие требует согласования преподавателя в product.
