## Действия владельца

Включить Issues в Settings → General → Features. Проверить основную ветку main. В Settings → Rules/Branches создать правило для main с обязательным pull request и запретом обычных прямых изменений. Не назначать обязательными ещё не существующие проверки. Доступ преподавателя должен включать issues и PR.

## Действия участников

Подтвердить персональное распределение, выбрать лицензию, выполнить реальные коммиты со своими авторами. Один участник повторяет запуск по README и дополняет протокол. Согласования преподавателя записываются ссылкой/комментарием в product; автоматическое создание issue не является одобрением.

## Демонстрация

Показать паспорт и команду, загрузку PNG и готовый конспект, места хранения данных, путь через очередь и ML, карту функций, результаты тестов, три наблюдения, план и риски. Затем открыть PR, main и тег lab-1. Ссылки на сдаваемые документы давать через итоговый тег.
